# Руководство для разработчика тестов

## Вариант 1 — Word (.docx) → конвертер → Moodle

Самый простой путь если привычно работать в Word.

### Правила оформления файла

```
Тема: Название раздела           ← необязательно, но помогает структуре

Текст вопроса (одна строка)
Неправильный ответ
Неправильный ответ
Правильный ответ                 ← ВЫДЕЛИТЬ ЦВЕТОМ (любым)
Неправильный ответ

Следующий вопрос
...
```

**Обязательные правила:**
- Каждый вопрос и каждый вариант ответа — отдельная строка
- Правильные ответы — цветной шрифт или цветная заливка текста
- Может быть несколько правильных (выделить все)
- Перед ответами — **не нужно** писать A/Б/В или 1/2/3

**Что не поддерживается:**
- Вопросы на расстановку порядка — пропускаются
- Вопросы с картинками — текст сохранится, картинка нет

**Запуск конвертера:**
```bash
# Поменять INPUT/OUTPUT в начале файла, затем:
python3 tools/docx_to_gift.py
```

## Вариант 2 — GIFT формат (рекомендуется)

Текстовый файл `.gift` — пишется в любом редакторе, импортируется напрямую в Moodle без конвертации. Быстрее и надёжнее.

```
// Одиночный выбор
::Название вопроса::Текст вопроса?{
  =Правильный ответ
  ~Неправильный ответ
  ~Неправильный ответ
}

// Множественный выбор (сумма % правильных = 100)
::Название вопроса::Текст вопроса. Выберите 2:{
  ~%50%Правильный 1
  ~%50%Правильный 2
  ~%0%Неправильный
  ~%0%Неправильный
}
```

Импорт: Moodle → Банк вопросов → Импорт → **GIFT**

## Вариант 3 — iSpring QuizMaker

Если нужны картинки, аудио, сложная логика ветвления.
Экспорт → QTI 2.0 → импорт в Moodle (Банк вопросов → Импорт → **IMS QTI 2.0**).

---

## Сравнение

| | Word + конвертер | GIFT | iSpring |
|---|---|---|---|
| Порог входа | Низкий | Средний | Низкий |
| Картинки | ✗ | ✗ | ✓ |
| Надёжность | ~90% вопросов | 100% | 100% |
| Требует ПО | Word + Python | Любой редактор | iSpring (платный) |

**Вывод:** для текстовых тестов — писать сразу в GIFT. Для тестов с медиа — iSpring.
