# tools/ — Конвертеры тестов для Moodle

## docx_to_moodle_xml.py — DOCX → Moodle XML

Конвертирует тест из Word в формат Moodle XML с встроенными картинками.

### Как использовать

1. Открыть файл `tools/docx_to_moodle_xml.py`
2. Поменять две строки в начале:

```python
INPUT  = '/путь/к/твоему/файлу.docx'
OUTPUT = '/путь/куда/сохранить.xml'
```

3. Запустить:

```bash
python3 tools/docx_to_moodle_xml.py
```

4. Импортировать в Moodle:
   **Банк вопросов → Импорт → Moodle XML → загрузить файл → Импортировать**

### Требования к DOCX

- Правильные ответы выделены цветом или цветным шрифтом
- Разделы тем начинаются со слова `Тема:`
- Зависимость: `pip install python-docx`

## qti_to_moodle_xml.py — QTI 1.2 XML → Moodle XML

Конвертирует тест из формата IMS QTI 1.2 в Moodle XML с встроенными картинками.

### Как использовать

1. Распаковать архив `.7z` — рядом с XML должна быть папка `qti_images/`
2. Открыть файл `tools/qti_to_moodle_xml.py`
3. Поменять три строки в начале:

```python
INPUT      = '/путь/к/файлу.xml'
IMAGES_DIR = '/путь/к/папке/qti_images'
OUTPUT     = '/путь/куда/сохранить.xml'
```

4. Запустить:

```bash
python3 tools/qti_to_moodle_xml.py
```

5. Импортировать в Moodle:
   **Банк вопросов → Импорт → Moodle XML → загрузить файл → Импортировать**

## docx_to_gift.py — DOCX → GIFT

Конвертирует тест из Word в текстовый формат GIFT. Картинки не поддерживаются — если вопросы с картинками, использовать `docx_to_moodle_xml.py`.

### Как использовать

1. Открыть `tools/docx_to_gift.py`, поменять две строки:

```python
INPUT  = '/путь/к/файлу.docx'
OUTPUT = '/путь/куда/сохранить.gift'
```

2. Запустить:

```bash
pip install python-docx
python3 tools/docx_to_gift.py
```

3. Импортировать в Moodle:
   **Банк вопросов → Импорт → формат GIFT → загрузить файл → Импортировать**

### Требования к DOCX

- Правильные ответы выделены цветом или цветным шрифтом
- Разделы тем начинаются со слова `Тема:`
- Вопросы-расстановки («Расставить в правильной последовательности») пропускаются — GIFT не поддерживает этот тип

## qti_to_gift.py — QTI 1.2 XML → GIFT

Конвертирует тест из формата IMS QTI 1.2 в GIFT. Стандартная библиотека Python, без зависимостей.

**Ограничение:** вопросы с картинками — текст сохраняется, картинка теряется. Если нужны картинки — использовать `qti_to_moodle_xml.py`.

### Как использовать

1. Открыть `tools/qti_to_gift.py`, поменять строки:

```python
INPUT  = '/путь/к/файлу.xml'
OUTPUT = '/путь/куда/сохранить.gift'
```

2. Запустить:

```bash
python3 tools/qti_to_gift.py
```

3. Импортировать в Moodle:
   **Банк вопросов → Импорт → формат GIFT → загрузить файл → Импортировать**
