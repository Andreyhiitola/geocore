# tools/ — Конвертеры тестов для Moodle

## Быстрый старт — графический интерфейс

```bash
# Один раз установить tkinter (Fedora/RHEL)
sudo dnf install python3-tkinter

# Запустить
python3 tools/convert.py
```

Откроется окно: выбрать конвертер, указать файлы через «Обзор…», нажать «Конвертировать».
После конвертации появится подсказка какой формат выбрать при импорте в Moodle.

---

## Какой конвертер выбрать

| Исходный файл | Есть картинки? | Конвертер | Формат импорта в Moodle |
|---------------|---------------|-----------|------------------------|
| `.docx` (Word) | нет | DOCX → GIFT | GIFT |
| `.docx` (Word) | да | DOCX → Moodle XML | Moodle XML |
| `.xml` (QTI 1.2) | нет | QTI → GIFT | GIFT |
| `.xml` (QTI 1.2) | да | QTI → Moodle XML | Moodle XML |

---

## Требования к DOCX

- Правильные ответы выделены **цветом** или цветным шрифтом
- Разделы тем начинаются со слова `Тема:`
- Вопросы-расстановки («Расставить в правильной последовательности») пропускаются — Moodle GIFT не поддерживает этот тип

## Требования к QTI (с картинками)

- Рядом с `.xml` должна лежать папка `qti_images/` (из распакованного архива `.7z`)
- В интерфейсе указать эту папку в поле «Папка картинок»

---

## Зависимости

```bash
pip install python-docx   # для DOCX-конвертеров
# QTI-конвертеры — только стандартная библиотека Python
```

---

## Импорт в Moodle

**Банк вопросов → Импорт → выбрать формат (GIFT или Moodle XML) → загрузить файл → Импортировать**

После импорта проверить вопросы отмеченные как `ПРОПУЩЕН` — у них не определился правильный ответ, нужно задать вручную.
