### AI-чат ассистент (Claude API)
**Приоритет:** высокий  
**Статус:** идея, не начато

Заменить офлайн-бот (`frontend/js/ui/chat.js`) на реальный AI-ассистент на базе Claude API.

**Что нужно:**
- Эндпоинт `POST /api/chat` в `backend/main.py` — принимает сообщение, возвращает ответ Claude
- `ANTHROPIC_API_KEY` в `.env` на VPS
- Системный промпт: геолог-консультант по Datamine, Leapfrog, JORC/ГКЗ, геостатистике
- Фронтенд: `chat.js` делает fetch на `/api/chat` вместо офлайн-паттернов
- Стриминг ответа (опционально — для ощущения живого чата)

**Ценность:** реальная помощь геологам прямо на сайте, конверсия в заявки на курсы.

### SCORM-плеер: почти-fullscreen режим
**Приоритет:** средний
**Статус:** реализовано в коде, ждёт теста на 8082 + деплоя

CSS/JS в теме `theme/geocore` скрывают хром Moodle (навбар, хлебные крошки,
футер, шторки курса/блоков) на странице SCORM-плеера (`#page-mod-scorm-player`)
— курс занимает весь вьюпорт браузера. Рядом с кнопкой «Выйти из активности»
добавлена кнопка «Во весь экран», переключающая true browser fullscreen
(Fullscreen API).

**Файлы:**
- `moodle/theme/geocore/scss/post.scss` — скрытие хрома, стили панели/кнопок
- `moodle/theme/geocore/javascript/scorm-fullscreen.js` — кнопка fullscreen,
  пересчёт высоты плеера после скрытия хрома
- `moodle/theme/geocore/config.php` — подключение JS через `javascripts_footer`
- `moodle/theme/geocore/version.php` — версия 1.1.0 (2026061500)

**Что нужно сделать:**
- [ ] Протестировать на `docker-compose.test.yml` (8082) на реальном SCORM-курсе
      (TOC-сайдбар, ресайз при входе/выходе из fullscreen, режим "Новое окно")
- [ ] Пересобрать и задеплоить образ `geocore-moodle` (ручной build, см. MOODLE_GUIDE.md —
      изменения в `moodle/theme/` требуют ручной пересборки образа)

**Ценность:** курс занимает весь экран — меньше отвлечения, лучше восприятие
SCORM-контента, особенно на ноутбуках с маленьким экраном.
