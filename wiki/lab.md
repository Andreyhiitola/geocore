# Лаборатория данных (lab.html)

## Текущее состояние

Страница `lab.html` существует. Содержит:
- Инструмент подготовки данных (UI готов, логика заглушена)
- Архив 7 демо-датасетов

## Запланированный функционал

### 1. Инструмент подготовки данных (CSV для Datamine)

Цель: очистить и подготовить CSV-файлы перед импортом в Datamine.
- Вход: collar / survey / assay в CSV/TXT
- Операции: валидация, исправление ошибок, нормализация
- Выход: очищенный CSV готовый к импорту в Datamine

### 2. 3D Визуализация (Three.js)

**Решение (2026-04-12):** начинаем с визуализации, не с построения.

Приоритет форматов — обсуждается:
- **Вариант A:** Скважины из CSV (collar + survey + assay) → 3D drill holes
- **Вариант B:** DXF каркас (экспорт из Datamine) → 3D wireframe mesh
- **Логичный порядок:** сначала скважины (продолжение инструмента подготовки), потом каркас поверх

### 3. База знаний решений (LLM Wiki)
