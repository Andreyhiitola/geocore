# Pitch-deck — Geocore-Academy

Инвесторская/партнёрская презентация, золото/тёмный фирменный стиль (см. `frontend/index.html` — источник токенов).

## Структура

Каждая версия — отдельная папка, файлы внутри не перезаписываются. Новая правка = новая папка (`v7`, `v8`, ...).

- `v5/` — PowerPoint, 15 слайдов (`.pptx` + экспорт `.pdf`). Редактируемая версия для правок вручную в PowerPoint.
- `v6/` — HTML-версия (`.html` + распечатанный `.pdf`), паритет по контенту с v5. Самодостаточный файл (картинки embedded base64), открывается в браузере без интернета; шрифты (Playfair Display/IBM Plex) грузятся с Google Fonts при наличии сети.
- `tools/` — `pptx_to_html.py`: автоконвертер, если партнёр присылает изменённый `.pptx` — не нужно вручную переносить правки в HTML.

## Актуальная версия

**v6** — самая новая по контенту (карта курсов по геологии/горному планированию, приложение на 60 курсов, обновлённый трек-рекорд). v5.pptx содержит тот же контент в редактируемом PowerPoint.

## Конвертер pptx → html

```bash
python3 tools/pptx_to_html.py v5/geocore_deck_v5.pptx v7/geocore_deck_v7_raw.html
```

Строит HTML как абсолютно позиционированную копию pptx (каждая фигура — div на своих координатах), не пытаясь угадать семантику вёрстки. Годится как черновик/сверка после правок партнёра — не заменяет ручную вёрстку в фирменном стиле (см. `v6/geocore_deck_mockup_v6.html` как эталон).
