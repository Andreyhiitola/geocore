# SCORM Pipeline — публикация курсов в Moodle

## Источник правды

Папка в Google Drive:
```
GEOCORE_Academy/
└── Эл_курсы/
    ├── Геологическое моделирование/
    ├── Геостатистика/
    ├── Комплексный кейс Тренажера/
    ├── Мат_методы анализа геохимии/
    ├── Нейросети для прогнозирования/
    └── Тренажер поисков и разведки/
```

Каждая папка — CourseLab-проект: содержит исходник `.wcl` + HTML-экспорт (`1/start.html`).  
Локальный кеш: `~/Google_disk/GEOCORE_Academy/Эл_курсы/`

## Что делает скрипт

`scripts/make-scorm.sh` для каждого курса:

1. **rsync** — копирует курс из `~/Google_disk/` во временную папку `/home/andysag/.cache/geocore-scorm/`
2. **zip** — пакует локально в SCORM ZIP (добавляет `imsmanifest.xml` SCORM 1.2)
3. **rsync** — копирует ZIP на VPS `/tmp/`
4. **docker cp** — кладёт ZIP в контейнер `geocore_moodle`
5. **PHP CLI** — создаёт SCORM-активность в Moodle
6. Временные файлы удаляются — постоянного хранения ZIP нет

ZIP-файлы нигде не сохраняются после загрузки. Источник правды — всегда `Эл_курсы` в Drive.

## Запуск

```bash
bash scripts/make-scorm.sh "/home/andysag/Google_disk/GEOCORE_Academy/Эл_курсы"
```

Опции:
```bash
# Только показать план, ничего не менять
bash scripts/make-scorm.sh "..." --dry-run
```

## Зависимости

- `zip`, `rsync` — установлены локально
- SSH alias `geocore` → `root@176.123.169.77` настроен в `~/.ssh/config`
- Контейнер `geocore_moodle` запущен на VPS
- Локальный кеш Google Drive смонтирован в `~/Google_disk/`

## Курсы в Moodle (courses-state.json)

Скрипт читает `scripts/courses-state.json` чтобы знать ID курса в Moodle.  
Если курс не найден в state.json — он пропускается.

```json
{
  "Геологическое моделирование": 12,
  "Геостатистика": 16,
  "Комплексный кейс Тренажера": 17,
  "Нейросети для прогнозирования": 18,
  "Мат_методы анализа геохимии": 19,
  "Тренажер поисков и разведки": 20
}
```

## Дубли и повторный запуск

Скрипт проверяет наличие SCORM-активности с таким же именем в курсе — дубли не создаются.  
Можно запускать повторно безопасно.

## После добавления нового курса

1. Добавить папку курса в `Эл_курсы` на Google Drive
2. Дождаться синхронизации в `~/Google_disk/`
3. Создать курс в Moodle вручную (или через `moodle-create-course.php`)
4. Добавить ID в `courses-state.json`
5. Запустить `make-scorm.sh`
